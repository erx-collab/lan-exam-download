# 🎓 LAN Exam

**Քննությունների desktop ծրագիր լոկալ ցանցի (Wi-Fi / LAN) համար**

Ուսանողները թեստը հանձնում են իրենց համակարգիչներից, դասախոսը տեսնում է ամեն ինչ իրական ժամանակում։
Ինտերնետ կամ հոստինգ պետք չէ․ բավական է, որ բոլորը լինեն նույն ցանցում։

## 🍎 Տեղադրում macOS-ում

1. Բացիր ներբեռնված `LAN-Exam-macOS.dmg` ֆայլը։
2. **LAN Exam**-ի պատկերակը քաշիր **Applications** պանակի մեջ։
3. Բացիր ծրագիրը **Applications** պանակից։

Առաջին բացման ժամանակ macOS-ը կարող է արգելափակել ծրագիրը, որովհետև այն App Store-ից չէ։ Այդ դեպքում՝

4. Կհայտնվի «*Apple could not verify "LAN Exam"…*» պատուհանը → սեղմիր **Done** (⚠️ ոչ թե *Move to Trash*)։
5. Բացիր  → **System Settings** → **Privacy & Security**։
6. Իջիր ներքև․ «*"LAN Exam" was blocked…*» տողի կողքին սեղմիր **Open Anyway**։
7. Մուտքագրիր Mac-իդ գաղտնաբառը և նորից սեղմիր **Open Anyway**։

> [!TIP]
> **macOS 14 (Sonoma) և ավելի հին տարբերակներում** ավելի հեշտ է․ աջ սեղմում (կամ Control + սեղմում) ծրագրի վրա → **Open** → **Open**։

8. Երբ ծրագիրը հարցնի՝

   > *Allow "LAN Exam" to find devices on local networks?*

   սեղմիր **Allow**։

> [!WARNING]
> Եթե սեղմես **Don't Allow**, ծրագիրը **չի կարողանա միանալ** դասախոսին։
> Ուղղելու համար՝ **System Settings → Privacy & Security → Local Network** → միացրու **LAN Exam**-ը։

Այս ամենը պետք է անել **միայն մեկ անգամ**։

## 🪟 Տեղադրում Windows-ում

1. Ներբեռնիր `LAN-Exam-Windows.exe`։ Տեղադրել պետք չէ․ ուղղակի բացիր ֆայլը։
2. Եթե հայտնվի «*Windows protected your PC*» → սեղմիր **More info** → **Run anyway**։
3. Եթե Windows Firewall-ը հարցնի → սեղմիր **Allow access**։
4. Եթե հակավիրուսը արգելափակի ֆայլը՝ ավելացրու այն բացառությունների (exceptions) մեջ։

> [!NOTE]
> Առաջին բացումը կարող է տևել մոտ 10 վայրկյան։

## 📝 Քննության օրը՝ ուսանողների համար

1. 🔋 Լիցքավորիր նոութբուքը կամ վերցրու լիցքավորիչը։
2. 📶 Միացիր **նույն Wi-Fi ցանցին**, ինչին միացած է դասախոսը։ **Անջատիր VPN-ը**, եթե այն կա։
3. Բացիր **LAN Exam** → ընտրիր **Ուսանող** → գրիր **անունդ և ազգանունդ** (իրական, ինչպես ցուցակում)։
4. 🟢 Կանաչ կետը նշանակում է, որ դասախոսի համակարգիչը գտնվել է։ Սեղմիր **Մուտք**։
   - Եթե գտնված չէ՝ սեղմիր «*Մուտքագրել դասախոսի հասցեն ձեռքով*» և գրիր գրատախտակին գրված հասցեն (օրինակ՝ `192.168.1.10`)։
5. Կարդա գնահատման սանդղակը և սպասիր, մինչև դասախոսը սկսի քննությունը → սեղմիր **Սկսել քննությունը**։
6. Հարցերը կարող ես կարդալ **հայերեն** կամ **անգլերեն** (ՀԱՅ / ENG կոճակը վերևում)։
7. Ավարտելուց հետո սեղմիր **ՀԱՆՁՆԵԼ**։ Կարող ես հանձնել նաև, եթե ոչ բոլոր հարցերին ես պատասխանել (չպատասխանվածները ստանում են 0 միավոր)։

### ⚠️ Կանոններ

- Քննության ընթացքում ծրագիրը բացվում է **ամբողջ էկրանով**։
- **Alt + Tab, Cmd + Tab, պատուհանից դուրս գալը, ծրագիրը փոքրացնելը կամ փակելը** անմիջապես ծանուցվում են դասախոսին։
- Ժամանակն ավարտվելիս պատասխանները **հանձնվում են ավտոմատ**։

### 💾 Եթե ծրագիրը փակվեց կամ կապը կորավ

Պատասխաններդ չեն կորչում․ դրանք պահվում են դասախոսի համակարգչում յուրաքանչյուր սեղմումից հետո։
Բացիր ծրագիրը նորից և մուտքագրիր **ճիշտ նույն անունն ու ազգանունը**․ կշարունակես նույն տեղից։

## 👨‍🏫 Դասախոսի համար

1. Բացիր ծրագիրը → **Դասախոս** → մուտքագրիր մուտքանունն ու գաղտնաբառը (տրվում են առանձին)։
2. Թույլտվություններ՝
   - **macOS**՝ սեղմիր **Allow** Local Network-ի հարցման դեպքում, և եթե Firewall-ը հարցնի «*accept incoming network connections?*»՝ նույնպես **Allow**։
   - **Windows**՝ Firewall-ի հարցման դեպքում **Allow access**։ Ցանցի տեսակը պետք է լինի **Private**, ոչ թե Public։
3. **Վահանակ** էջում երևում է միացման հասցեն (օրինակ՝ `192.168.1.10:47800`)․ գրիր այն գրատախտակին՝ ձեռքով միանալու համար։
4. Երբ բոլոր ուսանողները երևում են **Live ուսանողներ** էջում՝ սեղմիր **Սկսել**։ Ժամաչափը (3 ժամ) կսկսի հետհաշվարկը։
5. 🔌 Միացրու լիցքավորիչը և **մի փակիր նոութբուքի կափարիչը** մինչև քննության ավարտը։
6. Ավարտից հետո արդյունքները կարելի է արտահանել **PDF** կամ **Excel** ձևաչափով (յուրաքանչյուր էջից)։

> [!IMPORTANT]
> **Ցանցի ստուգում․** դպրոցական և «guest» Wi-Fi ցանցերը հաճախ արգելում են սարքերի իրար միանալը (*client isolation*)։
> Քննությունից առաջ անպայման փորձիր 3–5 ուսանողի հետ նույն լսարանում և նույն ցանցում։
> Փորձից հետո **Վահանակ** էջում սեղմիր **Նոր սեսիա**՝ փորձնական տվյալները մաքրելու համար։

- Ծրագիրն աշխատում է **միայն լոկալ ցանցում**, ինտերնետ չի օգտագործում։
